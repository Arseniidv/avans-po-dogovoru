# Записка бухгалтеру

Отчёт строится командой `python3 report.py` из папки с заданием, дата по умолчанию — 10.11.2026 (можно задать свою через `--date`).

Что в нём: по каждому договору — таблица работ с ценой, выплаченной суммой и остатком, ниже итог по договору. Отменённые работы показаны для полноты, платить по ним не нужно.

Важные моменты:
- «Выплачено» — только деньги, которые реально ушли подрядчику на дату отчёта. Платёж в очереди (P-4, 150 000 ₽ по D-1) в оплату не включён, он показан отдельной строкой.
- Платежи без привязки к работе разнесены по работам по порядку: сначала закрываются ранее выполненные работы, пока хватает их цены. Если такая логика не соответствует тому, как вы договаривались с подрядчиком — скажите, поправлю.
- По W-14 (D-1) видно переплату 15 000 ₽ — это платёж «Материалы для съёмки» поверх цены работы. Если эти деньги должны засчитываться в счёт других работ, тоже дайте знать.
- По D-2 на 10.11 не хватило платежа P-8 (20 000 ₽, ушёл 12.11) — остаток по W-23 на проверочную дату 15 000 ₽.

Когда вернётесь — подтвердите, пожалуйста: порядок зачёта авансов по работам и судьбу переплаты по W-14.
