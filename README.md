# Тестовое задание: аванс по договору

Отчёт по оплатам подрядчикам: по каждой работе — цена, выплачено и остаток,
по каждому договору — итоги. Отчёт строится на произвольную дату.

## Запуск

Нужен Python 3.8+, сторонних библиотек нет — только стандартная библиотека.

```bash
cd avans-po-dogovoru

# отчёт на контрольную дату 10.11.2026 (по умолчанию)
python3 report.py

# отчёт на другую дату
python3 report.py --date 2026-09-30

# дополнительно сохранить CSV (открывается в Excel/таблицах)
python3 report.py --csv report.csv

# данные из другой папки
python3 report.py --data /path/to/data
```

## Что в отчёте

- По каждой работе: цена, сколько уже выплачено, сколько осталось оплатить.
- По каждому договору: итоги + суммы, не покрытые работами
  (переплата, платежи в очереди).
- Отменённые работы показаны для полноты, оплачивать по ним не нужно.

## Структура

```
report.py      — программа отчёта (csv + decimal, без float)
data/          — исходные данные: contracts.csv, works.csv, payments.csv, FORMAT.md
DECISIONS.md   — принятые решения и допущения (что, варианты, почему, последствия)
NOTE.md        — записка бухгалтеру: как читать отчёт и что подтвердить
```

## Ключевые допущения (подробно — в DECISIONS.md)

- «Выплачено» — только платежи, по которым деньги реально ушли на дату отчёта
  (`paid_at <= дата`). `queued` показан отдельно, `refunded` вычитается после возврата.
- Платежи без привязки к работе разносятся по работам «водопадом»: сначала
  закрываются ранее выполненные работы, пока хватает их цены.
- Деньги считаются точно, в `Decimal`, до копейки.
